# AI Blocker (прототип)

1. Android Studio -> New Project -> Empty Views Activity, package `com.example.aiblocker`, Kotlin, minSdk 26.
2. Замените AndroidManifest.xml; добавьте MainActivity.kt, AiBlockerService.kt, Rules.kt, GroqClient.kt,
   res/xml/ai_blocker_service.xml; обновите res/values/strings.xml.
3. Запустите -> откройте приложение -> включите службу AI Blocker в настройках спец. возможностей.
4. В приложении: вставьте ключ Groq, включите переключатель, нажмите "Сохранить".

Порядок проверки карточки: allow-список -> локальные правила (шаблоны, каналы, слабые признаки)
-> кэш вердиктов Groq -> запрос в Groq (пачкой до 15 карточек) -> автодобавление канала после 2 срабатываний.

## Что нового (v2)
- Автоскрытие: для сильных совпадений служба открывает меню карточки YouTube и нажимает «Не рекомендовать этот канал» (переключатель в приложении).
- Страница видео: служба читает название, канал и описание открытого видео, отправляет в Groq; если вердикт «ИИ», канал сразу попадает в «выученные».
- Модель по умолчанию `llama-3.3-70b-versatile`, порог 0.65, расширенный промпт. Старые сохранённые значения при первом запуске обновляются.
- Шаблоны `#ai...`, `#chatgpt`, `#нейросеть` убраны/сужены, чтобы не ловить `#airport` и уроки по ИИ.
- Страница канала: служба читает «О канале» и последние видео, один раз просит вердикт по каналу, запоминает его и закрывает страницу.
- В ленте канал запоминается после одного уверенного вердикта (>= 0.85) или двух обычных.
- Запасной ключ и запасная модель Groq: используются автоматически, если основной запрос вернул ошибку или лимит.
- Плашка теперь перехватывает нажатия (видео под ней не открыть), а свайпы повторяются на ленте через жесты (нужно право canPerformGestures: после обновления выключите и снова включите службу).
- В приложении есть «Журнал работы»: показывает, что делала служба (меню, Groq, закрытие страниц).
